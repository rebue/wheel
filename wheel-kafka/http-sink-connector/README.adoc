= Kafka Http Sink Connector

== 注册 sink 连接器

.http-sink-connector.json
[source,json,%]
----
{
    "name": "http-sink-connector",
    "config": {
        "connector.class": "rebue.wheel.kafka.httpsink.HttpSinkConnector",
        "tasks.max": 1,
        "topics": "http_sink",
        "http.api.url": "http://magic-api_svr:9999/test/test02"
    }
}
----

[source,curl]
----
curl -i -X POST -H "Content-Type:application/json" 127.0.0.1:8083/connectors/ -d @http-sink-connector.json
----

== 注销连接器

[source,curl]
----
curl -i -X DELETE 127.0.0.1:8083/connectors/http-sink-connector
----

== 查看连接器

[source,curl]
----
curl 127.0.0.1:8083/connectors/
----
